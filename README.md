# Artillery Duel · Turn-based Artillery Game

Free single-file HTML5 artillery duel against the AI. Set angle and power,
read the wind, blast craters into destructible terrain, and hit the enemy
turret 3 times to win. One HTML file, zero assets.

**Play:** https://shuangyueliao.github.io/artillery-duel/

- Drag out from your turret to aim (release to fire) or arrow keys + Space
- Two AI difficulties: Easy (wild guesser) / Hard (iterative solver with wind compensation and a 15% miss chance)
- Destructible terrain — shells carve craters and turrets slide into them
- Random wind (±10) every turn, first to 3 hits wins
- Local win/loss/streak stats, mute toggle, procedural WebAudio sounds
- Procedural canvas visuals, no dependencies, landscape-friendly
